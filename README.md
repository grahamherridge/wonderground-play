# Wonderground

[**Play Wonderground**](https://grahamherridge.github.io/wonderground-play/)

Make somewhere wonderful. Generate a seeded island, shape its mountains and coasts, and explore a raised miniature landscape.

Drag to roam, pinch or scroll to zoom, and twist two fingers to turn. Use Map / 2.5D, Tilt and Fit to change your view. New World discovers another island; the visible seed lets you revisit it.

Requires a browser with WebGL 2. This repository contains the published browser game files.

Published version: structured regional landforms, fixed terrain across zoom levels, error-aware mesh refinement and worker generation with progress. Sea level reuses the existing terrain.
